WBSL Board 포스터 분리 + 4:3 활동 이미지

분류
- 전체
- 포스터
- 학술 활동
- 연구실 활동
- 외부 활동

동작
- 포스터 항목은 전체 탭에 나오지 않고 포스터 탭에서만 보입니다.
- 포스터 이미지는 자르지 않고 기존 세로 비율(3:4 영역 안에서 contain)로 전체가 보입니다.
- 학술 활동 / 연구실 활동 / 외부 활동은 관리자에서 사진을 올리면 4:3 자르기 창이 뜹니다.
- 관리자에서 Category를 먼저 선택한 뒤 사진을 선택하세요.

적용 파일
- board.html
- board-detail.html
- admin.html
- script.js

Supabase 스키마 변경은 없어서 SQL 실행은 필요 없습니다.
기존 항목을 포스터로 바꾸고 싶으면 관리자에서 해당 항목 Category만 '포스터'로 수정하면 됩니다.
