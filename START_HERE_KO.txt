WBSL 홈페이지 관리자 기능 추가 패키지
=====================================

이 패키지는 기존 GitHub Pages 주소를 그대로 사용하면서
/admin.html 에서 논문, Board/News, 연구실 멤버, 메인 슬라이드 사진을
추가/수정/삭제할 수 있게 합니다.

[GitHub에 업로드할 파일]
- admin.html          새 파일
- admin.css           새 파일
- admin.js            새 파일
- supabase-config.js  새 파일 (Supabase 값 2개 입력 후 업로드)
- script.js           기존 파일을 이 파일로 교체

[Supabase에서 실행할 파일]
- supabase_setup.sql  GitHub에 올릴 필요 없음. Supabase SQL Editor에서 1회 실행.

--------------------------------------------------
1. 다른 계정으로 Supabase 프로젝트 만들기
--------------------------------------------------
원하는 Google/이메일 계정으로 Supabase에 로그인해서 프로젝트를 생성합니다.
ChatGPT 계정과 같을 필요가 없습니다.

--------------------------------------------------
2. 데이터베이스와 사진 저장소 만들기
--------------------------------------------------
Supabase > SQL Editor > New query
supabase_setup.sql 전체를 복사해서 Run 합니다.

이 SQL은 다음을 만듭니다.
- publications
- news
- members
- slides
- admin_users
- wbsl-images Storage bucket
- 공개 읽기 + 관리자만 쓰기 가능한 RLS 정책

--------------------------------------------------
3. 관리자 로그인 계정 만들기
--------------------------------------------------
Supabase > Authentication > Users에서 관리자 계정을 생성합니다.

그 다음 SQL Editor에서 아래 한 줄을 실행합니다.
이메일은 실제 관리자 이메일로 교체합니다.

insert into public.admin_users(email)
values ('YOUR_ADMIN_EMAIL@example.com')
on conflict (email) do nothing;

여러 명이 관리자라면 이메일별로 한 줄씩 추가하면 됩니다.

--------------------------------------------------
4. Project URL과 공개 키 넣기
--------------------------------------------------
Supabase Dashboard에서 Project URL과 Publishable key(또는 anon key)를 확인합니다.

supabase-config.js 파일을 열어 아래 두 값만 바꿉니다.

export const SUPABASE_URL = 'https://xxxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'sb_publishable_...';

절대로 service_role / secret key를 여기에 넣지 마세요.

--------------------------------------------------
5. GitHub에 업로드
--------------------------------------------------
WBSL-homepage 저장소의 루트에 다음을 업로드합니다.

admin.html
admin.css
admin.js
supabase-config.js
script.js

script.js는 기존 파일을 교체합니다.
assets/lab1.jpg 등의 기존 파일은 삭제할 필요 없습니다.

--------------------------------------------------
6. 관리자 페이지 접속
--------------------------------------------------
배포 후:

https://ilji0503.github.io/WBSL-homepage/admin.html

Supabase Authentication에서 만든 계정으로 로그인합니다.

관리 메뉴:
- Publications: 논문 추가/수정/삭제
- Board / News: 소식 + 사진 업로드
- Members: 구성원 + 프로필 사진
- Main Slider: 메인 사진 + 제목 + 순서

--------------------------------------------------
7. 홈페이지 반영 방식
--------------------------------------------------
관리자 페이지에서 저장하면 Supabase에 저장됩니다.
일반 홈페이지의 script.js가 Supabase에서 최신 데이터를 읽어옵니다.

- 메인 Recent Publications
- Publication 페이지
- 메인 Latest News
- Board 페이지
- People 페이지
- 메인 사진 슬라이더

에 자동 반영됩니다.

처음 script.js를 교체한 직후 이전 JS가 보이면 Ctrl + F5를 눌러 주세요.
GitHub Pages 캐시 때문에 몇 분 늦게 보일 수도 있습니다.

--------------------------------------------------
기존 데이터에 대해
--------------------------------------------------
Supabase에 아직 논문/소식/멤버 데이터가 하나도 없으면 해당 영역은 비어 보일 수 있습니다.
메인 슬라이드는 Supabase에 슬라이드가 없을 경우 기존 HTML의 lab1/lab2/lab3 슬라이드를 그대로 사용합니다.

기존 논문이나 소식이 있다면 관리자 페이지에서 한 번 등록해 주세요.
